ACABADOS VISUALES

Efectos de estampado

Diseñá la apariencia. Exportá para DTF.

Ajustes del efecto
Fondo y zona de aplicación
El fondo protegido queda plano. Para una máscara precisa, prepará primero la imagen en Rango de color.
Medida de impresión

300 DPI · PNG con transparencia

Salida: hasta 16 384 px por lado y 64 MP a 300 DPI.
Guía de técnicas y materiales

DTF: imprime esta apariencia como imagen plana. El bordado simulado funciona mejor con logos y letras amplias; no genera puntadas de máquina.

Serigrafía: usa tintas y pantallas. Tintas planas y tramas sirven para explorar el estilo; este PNG no es una separación de tintas.

Puff, glitter y metálico: aquí son simulaciones. El volumen, las partículas o la reflexión reales requieren vinilos, tintas o acabados especiales.

Sublimación: requiere soportes compatibles, como poliéster; aplicar una textura no cambia el proceso de impresión.

Comprobá detalles, color y adherencia con tu proveedor. Este editor exporta RGB, no una separación CMYK ni una base blanca del RIP.
