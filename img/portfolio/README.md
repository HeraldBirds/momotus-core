# Fotografías reales

Colocá aquí fotos autorizadas de tus prendas terminadas y detalles del estampado, sin alterar su resolución. En tienda/js/configuracion.js, gallery recibe entradas {title, image, consent:true}. Inicio muestra hasta seis trabajos autorizados.

Para pares de diseño y prenda terminada, editar comparisons en js/home-content.js. Cada entrada usa title, designImage, printedImage y consent:true. Solo agregar pares del mismo trabajo, con archivos existentes. La sección aparece cuando haya contenido configurado. Por defecto se muestra un mockup de catálogo ampliable, identificado como vista de referencia.
