# Fotografías de urbano / motor

Colocá aquí los mockups de camisetas indicados en MAPA-IMAGENES-TIENDA.csv. Las otras prendas van en variants/: ID-hoodie.webp, ID-sudadera.webp e ID-crop-top.webp.

Usá el ID del diseño base, no el ID 1000/2000/3000 de la variante. Reemplazar una foto con el mismo nombre conserva el producto, el precio y las tallas. No cambies resolución ni calidad al organizar los archivos.

Los productos en borrador se publican desde administracion/ después de confirmar nombre, imagen, precio y stock. Las imágenes por sí solas no publican un producto.

Los cinco espacios nuevos de este tema (ver ESPACIOS-URBANOS-HABILITADOS.md) ya están publicados: basta añadir sus mockups en las rutas indicadas.
